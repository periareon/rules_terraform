rules_terraform

Terraform Extensions

Two module extensions live in //terraform:extensions.bzl:

terraform_toolchains

Materializes one hub repo (@terraform_toolchains) that declares a toolchain per (version, platform) for the releases shipped in //terraform/private:versions.bzl — the three newest when the table was generated — and for any release a version tag asks for. For a tagged release the extension fetches that release's SHA256SUMS once and records the checksums as facts in MODULE.bazel.lock. rules_terraform's own MODULE.bazel use_repos the hub and register_toolchainss it, so downstream users get toolchain resolution for free. Per-(version, platform) http_archives are lazy; only the selected combination is fetched.

# Nothing to do beyond `bazel_dep` to use the newest shipped release.
bazel_dep(name = "rules_terraform", version = "...")

# To use another release:
terraform_toolchains = use_extension("@rules_terraform//terraform:extensions.bzl", "terraform_toolchains")
terraform_toolchains.version(version = "1.9.8", default = True)

terraform_toolchains.version

AttributeTypeDescription
versionstring (required)The release, e.g. 1.9.8. Shipped releases need no tag.
defaultbool (default False)Use this release when //terraform/settings:version is empty. Root module only; at most one tag may set it.

The hub declares a config_setting per known release, so the flag can select any of them: --@rules_terraform//terraform/settings:version=1.9.8.

terraform

Carries the deps tag class: the providers a lock file pins and the registry modules some directories' module blocks name, as one hub per tag.

terraform = use_extension("@rules_terraform//terraform:extensions.bzl", "terraform")

# One `deps` tag per lock file. `lock` brings the providers the lock pins;
# `roots` brings the registry modules named by the `module` blocks in those
# directories (root modules and shared libraries alike). Either may be
# omitted.
terraform.deps(
    name = "app",
    lock = "//path/to/module:.terraform.lock.hcl",
    roots = [
        "//path/to/module:main.tf",
        "//path/to/library:main.tf",
    ],
    # registry = "registry.opentofu.org",  # optional; defaults to registry.terraform.io
)

use_repo(terraform, "app")

@app is a terraform_dependency_group: every provider in the lock, the lock itself, and every registry module the roots name. A terraform_module that depends on it needs no lock attribute. @app//:providers and @app//:modules are the two halves, and @app//<namespace>_<name> is one provider. Name the hub after what it serves rather than after the tag.

Hubs are alias layers. The archives themselves go into pools shared by every hub of the extension: one repository per distinct provider archive (rt_prov_<registry>_<namespace>_<name>_<version>_<platform>) and one per distinct module archive (rt_mod_<registry>_<address>_<version>), so two hubs that agree on a version fetch and extract it once. Hub names share one namespace across every Bazel module that uses the extension; a duplicate is reported at evaluation time.

terraform.deps

AttributeTypeDescription
namestring (required)Hub repository name.
locklabelA .terraform.lock.hcl. Every provider it pins is fetched for every platform the registry publishes.
rootslabel_listDirectories whose module { source = "…" } blocks name registry modules, each as any .tf file inside it. Every *.tf in each directory is scanned; registry modules composed of other registry modules are followed.
rootlabelShorthand for a one-element roots.
registrystring (default empty)Registry host to query for lock entries and sources that name none. Empty means registry.terraform.io from this extension, registry.opentofu.org from the OpenTofu one.
